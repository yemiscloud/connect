## 🧩 How I Think About Engineering

I don't just want to build software that works.

I want to understand:

**What problem are we solving?
Who is using it?
What process are we improving?
What data does the business need?
And how can the system continue to scale as the business grows?**

That's why I describe my work as **Data Product Engineering**.

I combine the mindset of a developer, analyst and product engineer to build systems that are useful beyond the code itself.
